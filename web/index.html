Technical Assessment Documentation (Methodology, Architecture & Results)

1. Dataset & Preprocessing

Trained on 117 multi-domain intent patterns spanning 15 distinct categories (Speech Recognition, Deep Learning architectures, SLP concepts, weather, time, greetings, and out-of-scope fallback). Text preprocessing utilizes lowercasing, punctuation stripping, stemming/lemmatization, and Bag-of-Words feature representations across a 175-dimensional vocabulary (|V| = 175).

2. Deep Learning Architecture

A Deep Neural Network built and trained in PyTorch:
• Input Dimension: 175 (|V|)
• Hidden Layer 1: Dense(128) + BatchNorm1d + ReLU + Dropout(0.35)
• Hidden Layer 2: Dense(64) + BatchNorm1d + ReLU + Dropout(0.30)
• Hidden Layer 3: Dense(32) + ReLU + Dropout(0.20)
• Output Layer: Dense(15) + Softmax probability distribution.

3. Evaluation & Results

Optimized using Adam Optimizer (lr=0.003, weight decay=1e-4) and CrossEntropyLoss for 260 epochs.
• Dataset Overall Accuracy: 92.31%
• Macro Average Precision: 0.95 | Recall: 0.91 | F1-Score: 0.92
• Zero-latency client-side neural forward pass matched to PyTorch within 1.18e-07.

4. Speech Recognition (STT/TTS)

Combines Web Speech API (acoustic modeling + language decoding) and server-side Google Speech Recognition for voice capture. Response audio synthesized via SpeechSynthesis API for complete voice-in, voice-out interaction.
